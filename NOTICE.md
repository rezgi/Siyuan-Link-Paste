# Sources

Link Paste is inspired by the titled-link workflow of
[Titled Url](https://github.com/frostime/sy-titled-link). Metadata extraction
and card rendering adapt a locally extended version of
[Card Link](https://github.com/zuoez02/siyuan-plugin-card-link)
(MIT, Copyright 2023 Luto Yvan).
The insertion and command lifecycle are new and use SiYuan 3.8.11 APIs.
